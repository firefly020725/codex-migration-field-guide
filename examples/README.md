# 合成清单说明

[manifest.synthetic.json](manifest.synthetic.json) 是自定义设计示例，不是 Codex 官方格式，也不被本仓库的任何程序执行。所有名称均为虚构；`null` 表示尚未采集证据，不能解释成匹配或通过。

示例刻意分开：

- 文件身份和前缀证据；
- 父子关系与运行状态；
- 原媒体引用、候选原件及路径恢复策略；
- 原已缺失与本次新增失败；
- 源、目标在冻结之后各自追加的分支；
- 文件核验与用户界面核验。

真正实现工具时，需要增加严格的输入验证、路径约束、并发处理和异常恢复。这份示例不提供执行器，也不包含任何可以照搬为本机白名单的真实对象信息。
